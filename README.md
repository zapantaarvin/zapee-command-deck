# Zapee Command Deck

Internal operations dashboard for Zapee World Online Store — live task board, workflow, team & decision rights, finances, compliance, content, and full operating documents in one page.

**Live:** https://zapantaarvin.github.io/zapee-command-deck/

Static HTML/CSS/inline-SVG, no build step, no JavaScript framework. Edit `index.html` directly and push to update the live page (GitHub Pages serves straight from `main`).

Source material: `~/Documents/Business-Partnership/Zapee/zapee-world-sop.html` (Internal Operating Agreement & SOP), the 4-Pillar Operating Handbook, and the live Kanban Business Hub board.

⚠️ **This repo is public and contains real internal business data** — profit split, decision-rights thresholds, compliance status, and task detail. Public by deliberate choice (2026-08-22) so the team has a shareable link; keep that in mind before adding anything more sensitive (credentials, personal data) to this file.
